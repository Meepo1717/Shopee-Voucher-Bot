# Voucher Bot Generator

A simple static webpage that generates a random Malaysian phone number and a 6-digit TAC code per load.

Deployable via GitHub Pages.

---

**How to deploy:**

1. Fork this repo into your GitHub account (`Meepo1717`).
2. In the fork:
   - Go to **Settings → Pages**
   - Under **Source**, select the `main` branch and root `/`
   - Click **Save**
